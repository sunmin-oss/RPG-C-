# RPG-C-

> **利用C++製作的文字冒險RPG遊戲**  
這是一個基於C++的期末專題，目的是設計並實現一款簡單的文字冒險角色扮演遊戲 (RPG)。  
此專案結合了課堂所學的物件導向設計與遊戲邏輯開發，並展示了我對C++語言的熟練程度。

---

## 🛠 專案特色
- **物件導向設計**：使用類別來表示角色、怪物和道具等遊戲元素。
- **回合制戰鬥系統**：玩家和敵人依次攻擊，並計算傷害。
- **事件驅動邏輯**：隨機事件生成系統，讓遊戲更具可玩性。
- **存檔功能**：玩家可以保存遊戲進度並隨時加載。

---

## 🚀 安裝與執行
1. **克隆此專案**：
   ```bash
   git clone https://github.com/sunmin-oss/RPG-C-.git
   cd RPG-C-
   ```

2. **編譯程式碼**：
   確保你已安裝 GCC 或其他 C++ 編譯器：
   ```bash
   g++ -o RPG main.cpp character.cpp monster.cpp -std=c++11
   ```

3. **執行遊戲**：
   ```bash
   ./RPG
   ```
